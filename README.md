\*\* HELICOPTER SHOOTER GAME



A 2D helicopter shooter game developed in C# using Windows Forms and Object-Oriented Programming concepts.



\* About the Project



This project was developed as part of my first-year Computer Science coursework. The game allows the player to control a helicopter, shoot incoming enemies, avoid obstacles, and earn points.



\* Features



* Helicopter player control
* Shooting mechanism
* Enemy UFOs
* Moving obstacles
* Collision detection
* Score management
* Start and game-over screens
* Different game objects managed through separate classes



\*Technologies Used



* C#
* .NET
* Windows Forms
* Object-Oriented Programming
* Visual Studio



\* OOP Concepts Used



* Classes and Objects
* Inheritance
* Interfaces
* Encapsulation
* Enums
* Separation of responsibilities



\*Project Structure



* Enums/
* Game/
* GameObjects/
* Interfaces/
* Managers/
* Properties/
* Resources/



\*How to Run

* Clone or download this repository.
* Open Helicopter Shooter Game.slnx in Visual Studio.
* Build the solution.
* Run the project.



\*What I Learned



Through this project, I practiced C# programming, object-oriented design, GUI development, collision handling, game logic, and organizing a larger program into multiple classes and components.
